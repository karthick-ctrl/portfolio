## 🚀 Running Locally

You can run this project locally with any static web server:

### Option 1: Python
```bash
python -m http.server 3000
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Option 2: Node.js (npx serve)
```bash
npx serve .
```

### Option 3: VS Code Live Server
Right-click `index.html` and click **"Open with Live Server"**.

## 🌐 Instant Deployment

### Deploy to Vercel (Recommended)
1. Push this folder to a GitHub repository: `https://github.com/karthick-ctrl/portfolio`.
2. Go to [vercel.com](https://vercel.com), import your repository, and click **Deploy**.
3. Your site will be live instantly with a free SSL domain!

### Deploy to GitHub Pages
1. Go to repository **Settings** -> **Pages**.
2. Under **Source**, choose `Deploy from a branch` -> `main` -> `/root` -> **Save**.
